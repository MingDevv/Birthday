# 🌠 แผนการออกแบบระบบดาวตกในฉากหลัง (Cosmic Shooting Stars & Meteor Shower System)
> **เอกสารออกแบบสถาปัตยกรรมกราฟิก 3D สำหรับฉลองวันเกิดครบรอบ 16 ปี "ข้าวหอม" 💜**

---

## 1. วิสัยทัศน์และแนวคิด (Design Vision)

ในเวอร์ชันปัจจุบัน ฉากหลังมีดาวตกเพียงเส้นเดียวที่พุ่งนานๆ ครั้ง (ทุก 4 - 8 วินาที) ทำให้ฉากหลังยังดูนิ่งเกินไป 

เป้าหมายของการออกแบบใหม่นี้คือการเพิ่ม **"ฝนดาวตกแห่งความปรารถนา (Starlight Meteor Shower)"** ในห้วงอวกาศลึกด้านหลัง เพื่อให้บรรยากาศมีชีวิตชีวา อบอุ่น โรแมนติก และชวนฝัน โดยมีหลักการสำคัญดังนี้:

1. **อยู่เฉพาะในฉากหลัง (Deep Background Only):** ดาวตกจะพุ่งผ่านที่ระยะไกล ($R = 250 - 450$ หน่วย) รอบนอกระบบสุริยะ **ไม่พุ่งตัดผ่านหน้าจอหรือบดบังดาวเคราะห์และดวงใจตรงกลาง**
2. **คุมโทนสีโปรดของข้าวหอม (Cosmic Purple Dream):** หางดาวตกไม่ได้เป็นแค่เส้นสีขาวเรียบๆ แต่จะมีการไล่เฉดสี (Color Gradient) โทนสีม่วงลาเวนเดอร์, ชมพูโรส, ฟ้าคริสตัล และทองแชมเปญ
3. **มีจังหวะที่เป็นธรรมชาติ (Natural Rhythmic Timing):** มีทั้งดาวตกเดี่ยวพุ่งแวบผ่านเป็นระยะ และระลอกฝนดาวตกชุดเล็กที่พุ่งขนานกันอย่างสวยงาม
4. **ฟินาเล่เมื่อกดอธิษฐานขอพร:** เมื่อผู้ใช้กดปุ่ม *"อธิษฐานขอพรวันเกิด"* จะมีระลอกฝนดาวตกชุดใหญ่ (Grand Meteor Shower) พุ่งผ่านพร้อมกับพลุ 3D

## 2. องค์ประกอบภาพของดาวตก (Visual Anatomy of a Shooting Star)

```
        หัวดาวตก (Head)                       หางดาวตก (Ion Tail)                     ละอองท้ายหาง (Sparks)
   ╭──────────────────────╮          ╭──────────────────────────────────╮           ╭──────────────────────╮
   │ • ประกายแสงเพชรกลมโต  │          │ • เส้นแสงเรืองรองไล่ระดับความทึบ │           │ • ละอองเกสรดาวจิ๋ว   │
   │ • แสง Bloom นวลตา    │ ───────► │ • สีขาวสว่าง ➔ ม่วงลาเวนเดอร์     │ ────────► │ • ค่อยๆ สลายตัวใน    │
   │ • สีขาวสว่างจ้า      │          │ • ความยาวหาง 40 - 80 หน่วย       │           │   ความมืดอย่างนุ่มนวล│
   ╰──────────────────────╯          ╰──────────────────────────────────╯           ╰──────────────────────╯
```

### 🎨 จานสีของดาวตก (Meteor Color Palette)
- 💜 **Cosmic Lavender:** ขาวประกายเพชรไล่ไปสีม่วงลาเวนเดอร์ (`#ffffff` ➔ `#c084fc` ➔ `#7c3aed`)
- 🌸 **Starlight Rose:** ขาวประกายไล่ไปชมพูพาสเทล (`#ffffff` ➔ `#f472b6` ➔ `#db2777`)
- 💎 **Electric Sapphire:** ขาวประกายไล่ไปฟ้าครามคริสตัล (`#ffffff` ➔ `#38bdf8` ➔ `#0284c7`)
- ✨ **Champagne Gold:** ขาวประกายไล่ไปทองแชมเปญอวยพรวันเกิด (`#ffffff` ➔ `#fef08a` ➔ `#f59e0b`)

## 3. รูปแบบการปรากฏของดาวตก (Behavioral Patterns)

เราจะแบ่งรูปแบบดาวตกออกเป็น **3 รูปแบบ** ที่ทำงานประสานกัน:

### รูปแบบที่ 1: ดาวตกทั่วไปในฉากหลัง (Ambient Casual Meteors)
- **ความถี่:** ปรากฏทุกๆ **1.2 - 2.5 วินาที** (เฉลี่ยมีดาวตก 2 - 3 สายในจอพร้อมกันในทิศทางต่างๆ)
- **พฤติกรรม:** พุ่งเฉียงลงด้วยความเร็วและมุมตกกระทบที่สุ่มอย่างเป็นธรรมชาติ (30° ถึง 50°)
- **ความยาวหาง:** ปานกลาง (35 - 55 หน่วย) จางหายไปอย่างรวดเร็ว (ความเร็ว 0.6 - 1.0 วินาทีต่อเส้น)

### รูปแบบที่ 2: ระลอกฝนดาวตกสถิต (Periodic Meteor Clusters)
- **ความถี่:** เกิดขึ้นทุกๆ **15 - 20 วินาที**
- **พฤติกรรม:** ปรากฏดาวตกพุ่งขนานกันมาเป็นชุด **3 - 5 สาย** พร้อมกันจากทิศทางเดียวกัน ดั่งกลุ่มดาวตกเพอร์ซีอัส (Perseid Meteor Shower)
- **เอฟเฟกต์:** สร้างความตื่นตาตื่นใจ ให้ความรู้สึกเหมือนกำลังนั่งดูดาวตกกับคนพิเศษ

### รูปแบบที่ 3: ปรากฏการณ์ดาวหางลูกใหญ่ (Grand Fireball / Bolide Event)
- **ความถี่:** นานๆ ครั้ง ทุกๆ **35 - 45 วินาที**
- **พฤติกรรม:** ดาวตกดวงใหญ่พิเศษ พุ่งช้ากว่าปกติ (1.8 วินาที) มีหางยาวเป็นประกายสีทอง/ชมพูข้ามฟากฟ้า พร้อมทิ้งแนวละอองควันเรืองแสงสีม่วงไว้ชั่วขณะก่อนสลายไป

## 4. โครงสร้างเชิงเทคนิคและการประมวลผล (Technical Architecture)

เพื่อให้ได้ภาพที่สวยงาม ลื่นไหล **60 FPS** เต็มที่ และกินทรัพยากรน้อยมากบนมือถือ:

### 1. ระบบ Object Pool (Zero Garbage Collection)
- แทนที่จะสร้าง `new THREE.Mesh` หรือเส้นใหม่ทุกครั้งที่เกิดดาวตก (ซึ่งทำให้เบราว์เซอร์กระตุกจาก Garbage Collection)
- เราจะสร้าง **Meteor Pool** ล่วงหน้าไว้คงที่ **12 สายดาวตก** ในหน่วยความจำ GPU
- เมื่อถึงเวลาแสดงผล เพียงแค่อัปเดตตำแหน่งจุดเริ่มต้น-สิ้นสุด และเปิดค่า `opacity`
- เมื่อพุ่งเสร็จ จะนำกลับมาเข้าคิวเพื่อใช้ซ้ำทันที

### 2. โครงสร้างเรขาคณิต (Geometry & Material)
- **ตัวหาง (Trail Body):** ใช้ `THREE.BufferGeometry` ชนิด Instanced Strip หรือ Ribbon (ความหนา 1.2 - 2.0 หน่วย) เพื่อให้มองเห็นความหนาของเส้นแสงได้อย่างชัดเจน ไม่ใช่แค่เส้นผมบางๆ 1 พิกเซล
- **Shaders:** ใช้ Vertex Colors คำนวณความสว่างจากหัวจรดท้าย (Head $\alpha=1.0$ ไปยัง Tail $\alpha=0.0$) ร่วมกับ Additive Blending (`THREE.AdditiveBlending`) เพื่อให้แสงซ้อนทับกันแล้วสว่างเจิดจ้าอย่างเป็นธรรมชาติ

### 3. พิกัดปลอดภัย (Safe Boundary Enclosure)
```
          [ ขอบฟ้าอวกาศลึก R = 250 - 450 ]  <─── จุดเกิดและพุ่งของดาวตก
       ┌───────────────────────────────────────┐
       │     🌠                                │
       │                🌠                     │
       │       [ เขตระบบสุริยะ R < 95 ]         │
       │       ┌───────────────────────┐       │
       │       │    🪐      ♀️   🌍    │       │
       │       │         💖            │       │ <─── ปลอดภัย โล่งตา ไม่ถูกดาวตกบัง
       │       │      ♂️       ♃       │       │
       │       └───────────────────────┘       │
       │                                       │
       │                      🌠               │
       └───────────────────────────────────────┘
```

## 5. การเชื่อมโยงกับฟีเจอร์อื่นๆ (Integrations)

1. **เชื่อมกับปุ่ม "อธิษฐานขอพรวันเกิด" (Make a Wish):**
   - เมื่อผู้ใช้กดปุ่มขอพร ระบบจะสั่งกระตุ้น `triggerGrandMeteorShower(8)` ให้ดาวตกพุ่งผ่านพร้อมกัน 8 สาย โอบล้อมรอบระบบสุริยะ เสริมความอลังการให้กับพลุ 3D
2. **มุมมอง "ท่องกาแล็กซี่ 3D":**
   - เมื่อผู้ใช้กดดูกาแล็กซีมุมกว้าง ดาวตกจะยังคงพุ่งผ่านในระดับความลึกที่สอดรับกับแขนกาแล็กซี ทำให้เห็นมิติชัดลึก (Parallax Depth) ระหว่างดาวตก กาแล็กซี และตัวหนังสือ 3D "ข้าวหอม"

## 6. สรุปเปรียบเทียบ ก่อนปรับปรุง vs หลังปรับปรุง

| จุดเปรียบเทียบ | ระบบปัจจุบัน | ระบบใหม่ที่ออกแบบ |
|---|---|---|
| **จำนวนดาวตก** | 1 เส้น พุ่งเดี่ยวๆ | พูล 12 เส้น (มีดาวตกในฉากตลอดเวลา 2 - 4 สาย) |
| **ความถี่** | นานๆ ครั้ง (4.5 - 8.5 วินาที) | ต่อเนื่อง นุ่มนวล (ทุก 1.2 - 2.5 วินาที) |
| **ความหนาและสีของหาง** | เส้นเดี่ยวสีชมพูบางๆ 1px | แถบแสงเรืองรองไล่เฉด 4 สี (ม่วง/ชมพู/ฟ้า/ทอง) |
| **ปรากฏการณ์พิเศษ** | ไม่มี | มีฝนดาวตกเป็นชุด (Cluster) และดาวหางยักษ์ (Fireball) |
| **การผูกกับปุ่มขอพร** | มีแค่พลุ | พลุ + ฝนดาวตกชุดใหญ่ 8 สายพุ่งรอบขอบฟ้า |
| **Performance** | 60 FPS | 60 FPS (ใช้ GPU Buffer Pool ไม่สร้างขยะใน RAM) |
