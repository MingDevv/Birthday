## 0. ข้อความสั่งงาน (คัดลอกวางได้เลย)

> อ่านไฟล์นี้ทั้งหมด แล้วทำตามลำดับ **Phase 0 → 1 → 2 → 3 → 4 → 5** ห้ามข้ามเฟส
> 1. **ห้ามแก้ข้อความไทยเดิมทุกจุด** (`secretMessage`, `memoriesData.js`, `PLANET_CONFIG`, ข้อความใน popup/caption/HUD) การเน้นคำ "ข้าวหอม" ให้ทำด้วยการห่อ `<span>`/เปลี่ยนสไตล์ ไม่ใช่เขียนถ้อยคำใหม่ และ **ห้ามแตะ `optionalFeatures.js` กับรูป placeholder**
> 2. ทุกการแก้ต้อง **เปิดดูภาพ QA ด้วยตาเอง** ก่อนเขียนว่าผ่าน และ **เก็บโฟลเดอร์ `qa/round4-*` ไว้ใน repo** (ซิปรอบก่อนไม่มีภาพ `qa/round3-*` ที่ handoff อ้างถึง จึงตรวจย้อนไม่ได้)
> 3. ห้ามแก้ปัญหา "รก" ด้วยการเพิ่มหมอก/bloom — ให้ **ซ่อนของที่ไม่ควรเห็นจริงๆ** (`visible = false`) ไม่ใช่แค่ลด opacity
> 4. ค่าตัวเลขในแผน (ตำแหน่งกล้อง ขนาด สี) เป็น **ค่าตั้งต้น** ให้ปรับด้วยตาจากภาพ QA จนเข้าเกณฑ์ผ่าน
> 5. ผูกทุกอย่างกับ quality tier, `prefers-reduced-motion`, `?fx=off` เหมือนเดิม; ไม่อ้าง FPS จาก SwiftShader
> 6. จบแต่ละเฟส: `npm run build` + QA เฉพาะเฟส + บันทึกลง `ANTIGRAVITY_HANDOFF.md` ว่า **ทำอะไร / ดูภาพไหน / เกณฑ์ข้อไหนผ่าน-ไม่ผ่าน**

## 4. Phase 1 — เวทีเค้กต้องสะอาดและสวย

### 4.1 `solarSystem.setStage()` — ตารางความมองเห็นต่อ stage
สร้าง preset (แทนที่ `setFinaleMode/setFinaleHeart/setCakeStage`) โดย **ค่าเปลี่ยนแบบ lerp ไม่กระตุก** และ `visible=false` เมื่อ opacity ≈ 0

| กลุ่ม | explore | finale-align | finale-heart | **cake** | epilogue→explore |
|---|---|---|---|---|---|
| ดาวเคราะห์ | เห็น | เห็น (วงโค้ง) | เห็น | **ซ่อน** | เห็น (blend กลับ) |
| เส้นวงโคจร | 0.13/0.28 ตาม visited | 0.08 | 0.08 | **ซ่อน** | คืนค่าตาม visited |
| สายละอองดาววงโคจร + `sparkPoints` | เห็น | 25% | 0 | **ซ่อน** | เห็น |
| เส้นเชื่อมดาว→หัวใจ | เห็น | เห็น | เห็น | **ซ่อน** | เห็น |
| เส้นหัวใจใหญ่ | ตามเงื่อนไข | เห็น | เน้น 0.96 | **ซ่อน** | เห็นบาง |
| beacon/ป้ายดาว | เห็น | ซ่อน | ซ่อน | **ซ่อน** | เห็น |
| หัวใจกลาง | ขนาดปกติ | ปกติ | ปกติ | **ย่อ 0.3 ลอยเป็น topper เหนือเทียน** | คืนขนาด |
| กุหลาบ B612 | ตามเดิม | ซ่อน | ซ่อน | **ซ่อน** | ตามเดิม |

ตัวอย่างโครง:
```js
const STAGE = {
  explore:      { planets: 1, orbitPaths: 'byVisited', streams: 1,   links: 1, heartLine: 'auto', beacons: 1, heart: 1,    rose: 'auto' },
  'finale-align': { planets: 1, orbitPaths: 0.08, streams: 0.25, links: 1, heartLine: 1, beacons: 0, heart: 1, rose: 0 },
  'finale-heart': { planets: 1, orbitPaths: 0.08, streams: 0,    links: 1, heartLine: 'emph', beacons: 0, heart: 1, rose: 0 },
  cake:         { planets: 0, orbitPaths: 0,    streams: 0,    links: 0, heartLine: 0, beacons: 0, heart: 'topper', rose: 0 },
};
// ทุกเฟรม: current[k] = lerp(current[k], target[k], 1 - Math.exp(-delta*5));
// ถ้า current[k] < 0.01 → object.visible = false (ลดงาน GPU/CPU)
```
**และต้องมี `finaleBlend`** (BUG-6): `pos = lerp(orbitPos, finalePos, finaleBlend)`; ตอนออกฉากจบ tween `finaleBlend → 0` ใช้เวลา ≥ 1.2s แล้วค่อยปล่อยให้ `orbitClock.scale` กลับ 1

### 4.2 ออกแบบเค้กใหม่ (`src/scene/cosmicCake.js`)
**เป้าหมายภาพ:** เค้กพาสเทลเรียบหรู เปล่งแสงอุ่นจากเทียน อ่านออกทันทีว่า "เค้กวันเกิด 16 เทียน" และเป็นพระเอกเดียวของเฟรม

- **จาน/ฐาน:** แผ่นกลม `r≈21` สูงบาง สีโรสโกลด์ (`metalness .7, roughness .25`) + วงแหวนเรืองแสงบางสีชมพูอ่อนใต้จาน เป็นจุดยึดสายตา
- **ชั้นเค้ก (ทึบทั้งหมด)** `MeshPhysicalMaterial { transparent:false, transmission:0, roughness:.38, clearcoat:.55, sheen:.6 }`
  - ล่าง `#b99af0` (ม่วงลาเวนเดอร์) · กลาง `#f7a8c8` (ชมพู) · บน `#fff0e0` (ครีม)
  - ขอบทองบาง `#ffd98e` ใต้แต่ละชั้น (แทน TorusGeometry ขาวโปร่งเดิม)
- **รายละเอียดที่ทำให้ดูเป็นเค้ก:** ไข่มุก `InstancedMesh` (24–32 เม็ด/ชั้น) ที่ขอบชั้น, หยดครีม (drip) ด้วยแคปซูลสั้นรอบชั้นบน, ดาวเล็กๆ (sprite) 8–12 ดวงลอยหมุนช้ารอบเค้ก
- **ขนาด:** ปรับ `group.scale` ให้เค้กสูง ~42–48% ของความสูงเฟรมใน 16:9 (ค่าตั้งต้นเดิม 2.05 อาจใช้ต่อได้ — ปรับด้วยตา) และเว้นพื้นที่ล่างสำหรับข้อความลับและปุ่ม

### 4.3 เทียน 16 เล่มและเปลวไฟ
- **จัดเป็น 2 วง:** วงนอก 10 เล่ม รัศมี `≈ 7.6`, วงใน 6 เล่ม รัศมี `≈ 3.6` (ชั้นบนรัศมี 9) หมุนวงในออกเฟส ½ ช่อง เพื่อไม่ให้ทับกันในมุมมอง
- ความสูงสุ่ม `5.0–5.8` (seed คงที่ ไม่สุ่มทุกครั้ง), รัศมี `0.40–0.46`
- ลายเกลียวสีขาว–ชมพู–ทอง ด้วย `CanvasTexture` เรียบง่าย + ไส้เทียนสีเข้ม (ทรงกระบอกเล็ก)
- **เปลวไฟ:** Sprite จาก canvas ทรงหยดน้ำ (แกนขาวเหลือง `#fff4c2` → ส้ม `#ffa83c` → โปร่งใส) ขนาด ~`1.6×2.8`, additive, กระพริบด้วย noise เบาๆ (scale/rotation เล็กน้อย) **ไม่ tint ชมพู**
- แสง: `PointLight` อุ่น `#ffb36b` ดวงเดียวเหนือเค้ก ความเข้มต่ำ เฉพาะ tier `high/ultra` ให้เห็นแสงตกบนครีม (tier ต่ำใช้ emissive เพิ่มบนชั้นบน)
- เมื่อเทียนดับ: เปลวหด→ควันดาวเล็กๆ ขึ้นแล้วหายไป (มีอยู่แล้ว ปรับให้เข้ากับเปลวใหม่) และ **ตรวจ `dispose()` ครบ**

### 4.4 กล้องและองค์ประกอบภาพฉากเค้ก
- ค่าตั้งต้น desktop: `camera.position (0, 40, 120)`, `target (0, 8, -5)`, `fov 38–40` (มุมก้ม ~20–28° เห็นวงเทียนและหน้าเค้ก)
- portrait: `position (0, 55, 175)` เพื่อให้เค้กไม่ล้นจอ
- หัวใจ topper ลอยสูงกว่าเปลวเทียน ~8–10 หน่วยในหน่วยของเค้ก ขนาด ~0.3 เต้นตามเพลง
- ข้อความลับ: คงข้อความเดิม วาง **ใต้ฐานจาน** ระยะห่างพอ ไม่ชนปุ่ม (action slot) ใช้ reveal แบบกวางแสง (wipe) ซ้ายไปขวาตอนเริ่มฉาก

### 5.2 ชื่อ 3D ตอนมาถึง (ใช้ซ้ำ `public/models/khaohom.svg`)
- แยกฟังก์ชันสร้างโครงชื่อจาก `name3DText.js` ออกเป็น `buildNameMesh()` ใช้ร่วมกันระหว่างตอนมาถึงกับโหมดกาแล็กซี (อย่าก๊อปซ้ำ)

  `worldWidth = 2 · d · tan(fov/2) · aspect · 0.55` (d = ระยะจากกล้องถึงชื่อ) และสูงไม่น้อยกว่า **14% ของความสูงจอ**

  - หน้าตัวอักษร: ครีมอุ่น `#fff1e6` ผสมโรสโกลด์ (ไล่สีแนวตั้ง) `emissive` ≥ 0.35
  - ขอบ/ด้านข้างหนา (extrusion): ชมพูสด `#ff5c93` `emissiveIntensity ≈ 0.6`
  - `clearcoat` + `envMap` (ใช้ env เดิมของหัวใจ) ให้มีไฮไลต์สะท้อนขอบ
  - แสงไฟหน้า (`DirectionalLight`/`RectAreaLight` ชั่วคราว) จากด้านหน้าเฉียงบน และไฟขอบหลังสีม่วงอ่อน เพื่อแยกตัวอักษรออกจากพื้นหลัง
  - **ฉากหลังตัวอักษร:** glow วงกลมนุ่ม (ไม่ใช่สี่เหลี่ยม) สีม่วงเข้มโปร่ง เพื่อเพิ่มคอนทราสต์ (รัศมีกลมเพื่อไม่ให้เกิดกรอบเหมือน BUG เดิม)

## 7. Phase 4 — QA อัตโนมัติ (ตัวตรวจที่ "จับบั๊กพวกนี้ได้จริง")

### 7.1 ตรวจวัตถุ 3D ที่มองเห็นในแต่ละ stage (กันเส้น/อนุภาคหลุด)
เปิด `window.__qaSceneAudit()` (เฉพาะ `?qa=`) คืนรายการ Object3D ที่ `visible` ทั้งสายพ่อ และเป็น `Line/LineSegments/Points/Sprite/Mesh`
```js
const ALLOW = {
  cake: [/^cosmicBirthdayCake/, /^cake/, /heart.*topper/i, /fireworks|burst/i, /skybox|stars|galaxy/i],
};
// QA: ใน flow.state==='FINALE_CAKE' ทุก object ที่ visible ต้องตรง ALLOW.cake — ถ้าไม่ตรง fail พร้อมพิมพ์ชื่อ
```
(ต้องตั้ง `name` ให้ทุก object สำคัญ เช่น `memoryLink-*`, `orbitPath-*`, `orbitStream-*`, `sparkPoints`)

### 7.2 นับเทียนไม่ทับกัน
ฉายตำแหน่งยอดเทียน 16 เล่มเป็นพิกเซลบนจอ แล้วตรวจ:
- ระยะห่างต่ำสุดระหว่างคู่ใดๆ ≥ **1.0% ของความกว้างจอ** และ
- จำนวนเปลวที่ติดไฟอยู่ในเฟรม = 16 (ก่อนเป่า) และ 0 (หลังเป่า)

### 7.3 คอนทราสต์/ขนาดของชื่อ
- ฉาย bounding box ของชื่อเป็นพิกเซลบนจอ → ตรวจ **สูง ≥ 14% ของความสูงจอ**
- ในกรอบนั้น คำนวณความสว่าง (relative luminance) ของพิกเซลที่สว่างสุด 25% เทียบกับค่ามัธยฐานของพื้นหลังรอบกรอบ ต้องได้อัตราส่วน **≥ 4.5 : 1**
- ถ้าไม่ผ่านให้บันทึกภาพ `name-contrast-fail.png`

### 7.4 ภาพ QA ที่ต้องสร้างและเปิดดู (desktop 1920×1080, portrait 390×844, landscape มือถือ)
`arrival-16`, `arrival-name`, `arrival-caption`, `cake-front`, `cake-top`(มุมสูงดูวงเทียน), `cake-lit`, `cake-blown`, `finale-align`, `finale-heart`, `epilogue-return` (ภาพกลางทางตอนดาวกำลังกลับวงโคจร), `galaxy-name`

### 7.5 สถานการณ์ทดสอบ
- เล่นครบ 5 ดวง → ฉากจบ → เป่าเทียน → epilogue → "เป่าเทียนอีกครั้ง" **5 รอบ** เช็ก geometry/texture/วัตถุใน scene ไม่เพิ่ม
- กด "ดูความทรงจำอีกครั้ง" กลางฉากเค้ก/หลังเป่า → ไม่มีของค้าง ปุ่มไม่ซ้ำ

- ตรวจ console ไม่มี warning ใหม่
