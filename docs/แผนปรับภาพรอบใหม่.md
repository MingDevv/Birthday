# แผนปรับภาพรอบใหม่ — ดาวลูกหมู-001

## เป้าหมาย

ยกระดับเว็บเซอร์ไพรส์วันเกิดให้เป็นประสบการณ์เดินทางผ่านกาแล็กซีสีม่วงที่ดูมีมิติและจำง่าย โดยทำให้ **ดาวหลักและความทรงจำอ่านออกก่อน** แล้วค่อยเติมรายละเอียดภาพยนตร์ ไม่เพิ่มแสงหรืออนุภาคทั่วทั้งฉากจนภาพฟุ้งและแย่งกันเด่น

## ขอบเขตการตรวจรอบนี้

- ตรวจโค้ดใน branch ปัจจุบัน โดยเฉพาะ `src/main.js`, `src/style.css`, `src/scene/solarSystemHeart.js`, `src/scene/spiralGalaxy.js`, `src/scene/name3DText.js`, `src/core/quality.js` และข้อมูลใน `src/config/memoriesData.js`
- ใช้ภาพ QA ใน `qa/handoff/desktop.png` และ `qa/handoff/mobile.png` ประกอบการประเมิน ภาพเหล่านี้เป็นภาพที่มีอยู่ใน workspace ไม่ใช่ภาพแคปสดจากเว็บที่ deploy รอบนี้
- การเปิดเว็บ production ใน browser ถูกปฏิเสธสิทธิ์ในรอบนี้ จึงยังยืนยันภาพและพฤติกรรมบน URL ปัจจุบันโดยตรงไม่ได้

## สิ่งที่ควรแก้ก่อน

1. **จัดเฟรมและสัดส่วนฉากใหม่** — ภาพ QA แสดงวงโคจรขนาดใหญ่พาดข้ามจอ ดาวบางดวงชิดหรือหลุดขอบ และบนมือถือฉากดาวใช้พื้นที่กลางจอค่อนข้างน้อยเมื่อเทียบกับ HUD และพื้นที่ว่างด้านล่าง ให้คำนวณกรอบฉากจากกล้อง/viewport จริงและจัดดาวทุกดวงให้อยู่ใน safe area
2. **ลดความรู้สึกดาวพลาสติก** — หัวใจม่วงตรงกลางเด่นด้วยสีและความเงามาก แต่ยังดูเรียบ ส่วนดาวเคราะห์ดูเป็นลายกราฟิกเรียบง่าย ให้ใช้ texture ดาวที่มีอยู่ใน `public/textures/planets/` กับ material และแสงที่เหมาะ พร้อมตรวจว่าการโหลด texture สำเร็จและไม่ตกไปใช้ procedural fallback โดยไม่รู้ตัว
3. **ทำวงโคจรให้ช่วยอ่านตำแหน่ง** — ลดจำนวนเส้นที่ซ้อนกัน จัดวงรีให้สัมพันธ์กับระนาบและกล้อง ใช้เส้นหลักบางชัด สีคอนทราสต์พอดี และทำเส้นรองให้จางลง วงโคจรควรเป็นกรอบนำสายตา ไม่ใช่ลวดลายที่พาดตัดดาวหลัก
4. **ลดภาระ HUD โดยเฉพาะมือถือ** — ย่อแผงชื่อ/ตัวนับดาวให้เป็นแถบสั้น จัดปุ่มมุมมอง เพลง และคำอวยพรไม่ให้บังฉาก ปรับข้อความแนะนำให้สั้นและใช้ไอคอน/คำอธิบายเมื่อแตะ
5. **จัดระดับแสงใหม่** — เก็บ bloom ไว้เฉพาะดาวสว่างและไฮไลต์หัวใจ ลดจุดเรืองฟุ้งรอบวัตถุ แล้วเพิ่มรายละเอียดผ่านแสงด้านสว่าง เงา และ rim light ที่มีทิศทางแทนการเพิ่ม glow

## ทิศทางภาพที่แนะนำ

- **จานสี:** midnight indigo เป็นฐาน, violet/lavender เป็นสีประจำเรื่อง, magenta เป็นสีรอง และสีขาวนวลใช้เฉพาะจุดสว่าง ใช้สีธรรมชาติของดาวเคราะห์เพื่อแยกแต่ละดวง ไม่ย้อมวัตถุทุกชิ้นเป็นม่วง
- **จุดเด่น:** ทำดาวลูกหมู-001 เป็น hero object ที่มีขอบแสงและพื้นผิวชัด หัวใจเป็นสัญลักษณ์กลางฉากที่มีวัสดุโปร่งใส/คริสตัลอย่างพอดี ไม่สว่างจนกลบดาวอื่น
- **กาแล็กซี:** แบ่งระยะ foreground, midground และ background ด้วย parallax บาง ๆ ใช้ฝุ่นอวกาศ/nebula เป็นกลุ่มก้อนกว้างกับแนวมืด (dust lane) แทนการเพิ่ม sprite วงกลมจำนวนมาก
- **วงโคจร:** ใช้ ellipse/ribbon บาง ๆ มีความลึกจาก opacity และระยะหน้า-หลัง เพิ่ม marker แสงเคลื่อนที่เป็นช่วง ๆ แค่ 1–2 จุดต่อวง
- **ชื่อ “ข้าวหอม”:** แสดงเฉพาะโหมดมุมไกลตามพฤติกรรมเดิม แต่ทำเป็นตัวอักษรไทยนูนที่มีความลึกจริงและอ่านออกจากระยะไกล ใช้สี ruby/deep red เป็นตัวหน้า เติมขอบม่วงบาง ๆ และแยกชั้นหลังฉากให้ชัด
- **ช็อตอวยพร:** เมื่อกดขอพร ให้มีช่วงเงียบสั้น ๆ แล้วจุดพลุดาวเป็น burst ชัดเจน 2–3 ระลอก พร้อมข้อความอวยพรที่อ่านง่าย ลดประกายค้างหลังจบ

## ลำดับการทำงาน

### P0 — จัดองค์ประกอบและแก้ภาพอ่านไม่ออก

- ปรับ `heroCamera()`/กล้องและขอบเขต controls ให้ระบบดาวอยู่กลางภาพทั้ง desktop และมือถือ
- กำหนด safe area สำหรับ HUD, ข้อความชื่อ และปุ่มหลัก ตามสัดส่วน 16:9, จอมือถือแนวตั้ง และจอเตี้ย
- ลดวงโคจรที่ล้นจอ/ซ้อนจนเป็นกรอบใหญ่ และเพิ่มขนาดดาวหลักบนมือถือ
- ย่อ HUD มือถือให้เหลือข้อมูลสำคัญ: ชื่อดาว, ความคืบหน้า, ปุ่มเสียง, ปุ่มอวยพร

**ผ่านเมื่อ:** ดาวสำคัญไม่ถูกตัดหรือถูก HUD บัง; ภาพแรกเห็นศูนย์กลางและดาวเคราะห์ได้ชัดใน 2–3 วินาที

### P1 — ปั้นวัสดุและแสงดาวให้คม

- ไล่ตรวจ texture loader และ fallback ใน `solarSystemHeart.js`; ตรวจ color space, mipmap, anisotropy และการ map texture ให้ตรงชนิดดาว
- ใช้ `MeshStandardMaterial`/`MeshPhysicalMaterial` อย่างมีเหตุผล: roughness แยกตามพื้นผิว, bump/normal แบบเบา และ specular highlight ไม่ล้น
- ใช้ key light กลางฉาก, fill อ่อน, rim light จำกัดทิศทาง ปรับ heart material ให้ลดสีชมพูสะท้อนจัดและเห็นรูปทรง/เหลี่ยมชัดขึ้น
- เพิ่ม atmosphere rim บาง ๆ ให้ดาวบางดวงด้วย shader/geometry ที่ไม่ทำ halo ใหญ่
- ตรวจแหล่งที่มาและ license ของ texture ใน `CREDITS.md`; ไฟล์ใน `public/textures/planets/` มีอยู่แล้ว จึงยังไม่ต้องเพิ่ม asset ใหม่ก่อนตรวจของเดิม

**ผ่านเมื่อ:** เห็นลายพื้นผิวและเส้นแบ่งแสง-เงาเมื่อซูมเข้า; สีไม่ clip; glow ไม่ทำให้ขอบดาวละลาย

### P2 — ทำกาแล็กซีและวงโคจรให้มีมิติ

- ปรับ `spiralGalaxy.js` ให้มีแขนกาแล็กซีที่อ่านเป็นมวลต่อเนื่อง มีช่องว่างกลางพอดีกับฉากดาวและมี dust lane มืดตัดผ่านบางส่วน
- เพิ่ม parallax แยกชั้นอย่างช้า ๆ ไม่หมุนทุกชั้นด้วยความเร็วเท่ากัน
- ปรับวงโคจรใน `solarSystemHeart.js` ให้เส้นหลักอ่านง่ายและแยกความลึกด้วย opacity/สี ลดเส้นอนุภาควิ่งต่อเนื่องที่ทำให้เกิด noise
- ทำ warp tunnel เป็นช่วงสั้นเฉพาะการเดินทางเข้า/ออก ไม่แสดง streak และวงแหวนสว่างค้างในฉากปกติ

**ผ่านเมื่อ:** มองแล้วเข้าใจว่ากำลังอยู่ในระบบดาวที่ลอยอยู่ในกาแล็กซี; วงโคจรไม่แย่งจุดเด่นจากดาวและความทรงจำ

### P3 — ทำชื่อและโมเมนต์เซอร์ไพรส์

- ปรับ `name3DText.js`: ตัวเลือกหลักคือทำข้อความไทยเป็น mesh แบบ extrude จาก glyph ที่เตรียมไว้ใน Blender ด้วยฟอนต์ไทยที่มี license; คง Canvas texture เป็น fallback สำหรับเครื่อง/ฟอนต์ที่ไม่มี
- ตรวจตำแหน่ง ขนาด และการหันหน้าของตัวอักษรจากกล้องมุมไกลทั้ง desktop และมือถือ ให้ชื่อ “ข้าวหอม” อยู่หลังระบบดาวแต่ไม่ถูกดาวหรือ bloom กลบ
- ทำ timeline ถึงดาวให้มี 3 จังหวะ: เห็นดาวจากระยะไกล → เคลื่อนผ่านประตูมิติ → เปิดแสงดาว/ชื่อ/คำอวยพร
- ปรับ fireworks เป็นดาวแตกเส้นคม มีแกนสว่างและเศษดาวที่ค่อย ๆ จาง จำนวนจำกัด; ผูกเอฟเฟกต์กับปุ่มขอพรและเสียงที่ผู้ใช้เปิดเอง
- รองรับ `prefers-reduced-motion` และปุ่มข้าม/หยุดการเดินทาง

**ผ่านเมื่อ:** ข้อความเห็นชัดทันทีในโหมดมุมไกล; พลุจบสะอาด ไม่ทิ้งฝุ่นหรือแสงฟุ้งเต็มจอ

### P4 — เก็บ performance และภาพสำหรับแชร์

- ใช้ quality tiers ที่มีอยู่ใน `src/core/quality.js`; จำกัดจำนวน particle, resolution scale และ post-processing ตามอุปกรณ์ก่อนเพิ่มเอฟเฟกต์ใหม่
- โหลด texture แบบ lazy ตามช่วงเดินทาง และพิจารณา KTX2 เฉพาะเมื่อวัดได้ว่าช่วยลดเวลา/หน่วยความจำจริง
- ทำ cinematic capture preset 16:9 และ 9:16 โดยคำนึงถึง safe area และจังหวะจบที่มีชื่อ/คำอวยพร
- อัปเดตภาพ QA แยก desktop, tablet/portrait และ mobile พร้อมภาพเปิด, มุมไกล, เปิดความทรงจำ และกดขอพร
- วัด performance บนอุปกรณ์จริงหรือ GPU ที่ใช้จริง; ค่า SwiftShader จาก Playwright ใช้จับ error/layout เท่านั้น ไม่ใช้ยืนยัน FPS

**ผ่านเมื่อ:** ฉากตอบสนองต่อการลาก/แตะได้ดี ไม่มี console error และเอฟเฟกต์ลดคุณภาพเองเมื่ออุปกรณ์ช้า โดยยังเห็นดาวหลักชัด

## เครื่องมือที่ควรใช้

| เครื่องมือ | ใช้ทำอะไร |
|---|---|
| Three.js และ GSAP (ของเดิม) | สร้างฉาก วัสดุ วงโคจร และ timeline เดินทาง ไม่ต้องเปลี่ยน engine |
| Blender | ปั้น hero star/หัวใจ, ทำ text mesh ภาษาไทย, ตั้งแสงและ export GLB ที่ optimize แล้ว |
| Blender Shader Editor | สร้าง texture/normal แบบ procedural หาก texture ดาวที่มีไม่พอ |
| Playwright + `scripts/visual-qa.mjs` | จับภาพ flow ซ้ำใน viewport เดิม ตรวจ overflow และ console |
| Chrome DevTools / Spector.js | ตรวจ draw calls, shader, GPU time และ overdraw บนเครื่องจริง |
| KTX2/Basis Universal (ภายหลัง) | บีบอัด texture เมื่อวัดแล้วว่าขนาดดาวน์โหลดหรือ VRAM เป็นคอขวด |

ยังไม่แนะนำให้เพิ่ม library post-processing หรือ asset model จำนวนมากในรอบแรก ให้แก้ framing, texture และแสงก่อน เพราะสิ่งเหล่านี้ให้ผลกับความคมและความสวยมากกว่าเพิ่มจำนวนเอฟเฟกต์

## แนวทางทำงานและการตรวจรับ

1. เก็บ baseline ใหม่จากเว็บ/โค้ด revision ปัจจุบันก่อนลงมือ เพราะภาพ `qa/handoff/` อาจไม่ตรงกับ production ล่าสุด
2. ทำ P0 ก่อน แล้วดูภาพที่ viewport เดิมก่อนเริ่มเฟสถัดไป
3. รัน `npm run build` และ `npm run visual:qa` หลังแก้; เปิดดูภาพเอง ไม่สรุปจาก build อย่างเดียว
4. ทดสอบ mouse, touch, เสียง, reduced motion, texture load failure, WebGL context restore และ resize
5. คง flow เดิม: Happy Birthday → ท่องกาแล็กซี → เดินทาง → ดาวลูกหมู-001 → ความทรงจำ/คำอวยพร
6. คงข้อความส่วนตัวและเพลงเดิม; ตรวจ autoplay/สิทธิ์เพลงก่อนทำคลิปหรือเผยแพร่ social
7. บันทึกไฟล์ที่แก้และข้อจำกัดจริงทุกเฟส อย่าเรียกภาพว่า photorealistic หากรายละเอียดพื้นผิวยังเป็น procedural แบบ stylized

## ลำดับความสำคัญเมื่อทำจริง

**P0 เฟรมและ HUD → P1 วัสดุ/แสง → P2 กาแล็กซี/วงโคจร → P3 ชื่อ/เซอร์ไพรส์ → P4 performance/ภาพแชร์**

หัวใจสำคัญของงานรอบนี้คือทำให้ภาพดูแพงด้วย composition, surface detail และแสงที่มีทิศทาง ก่อนเติมของเพิ่ม เมื่อฉากอ่านชัดแล้วค่อยใส่รายละเอียดเล็ก ๆ เป็นจุดนำสายตา
