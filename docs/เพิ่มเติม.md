# งาน (Task): พัฒนาระบบเว็บดวงดาวความทรงจำ 3D (Interactive 3D Memory Planet) สไตล์ Give Love Studio

## 1. ภาพรวมโปรเจกต์และบทบาทของ Agent (Project Overview & Role)
คุณคือ Senior Creative Technologist และผู้เชี่ยวชาญด้าน 3D Web Creative มีหน้าที่พัฒนาเว็บแอปพลิเคชัน 3D ดวงดาวความทรงจำ (Memory Planet of Love) ให้เหมือนและสวยงามเทียบเท่าคลิปต้นฉบับของ Give Love Studio

เว็บนี้สร้างขึ้นเป็นของขวัญวันเกิด/วันครบรอบสุดโรแมนติก โดยมี **ดวงดาว 3 มิติโทนพาสเทลเรืองแสง** ลอยอยู่กลางห้วงอวกาศระยิบระยับ และมี **หมุดความทรงจำ 5 จุด (5 Memories)** ปักอยู่รอบดาว เมื่อผู้ใช้คลิกเลือกหมุด กล้องจะซูมพาบินข้ามอวกาศเข้าไปอ่านการ์ดรูปถ่ายและข้อความซึ้งๆ อย่างนุ่มนวล พร้อมเพลงประกอบ BGM สุดอบอุ่น

---

## 2. เทคโนโลยีและโครงสร้างโปรเจกต์ (Tech Stack & Libraries)
- **3D Engine:** Three.js (`https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js`)
- **Camera Animation & Smooth Transitions:** GSAP 3 (`https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js`)
- **Camera Controls:** OrbitControls (`three/examples/jsm/controls/OrbitControls.js`)
- **Particle FX:** Canvas-Confetti หรือ Three.js Custom Starfield Particle System
- **รูปแบบการส่งมอบ:** Standalone Single File `index.html` หรือ Vite Modern Modular Project (ต้องพร้อมรันแบบไร้รอยต่อ Zero Missing Assets)

## 3. รายละเอียดและข้อกำหนดเชิงลึกในการพัฒนา (Detailed Specifications)

### เฟส 1: บรรยากาศห้วงอวกาศและดวงดาว (Cosmic Environment & The 3D Planet)
1. **ฉากหลังอวกาศโรแมนติก (Romantic Deep Space):**
   - ท้องฟ้าโทนสี Deep Midnight Blue ผสมม่วงเข้มไล่เฉด (`#08081A` ไปยัง `#140C2E`)
   - ระบบละอองดาว 3 มิติ (Starfield): สุ่มอนุภาคดาวประกายแสงกว่า 2,500 ดวงรอบทิศทาง พร้อมแอนิเมชันกระพริบระยิบระยับ (Twinkle effect)
   - แอนิเมชันดาวตก (Shooting Stars): มีลำแสงดาวตกสีขาวประกายทองพุ่งพาดผ่านขอบฟ้าทุกๆ 4–8 วินาที
2. **การปั้นและลงสีพื้นผิวดวงดาว (The Planet Sphere):**
   - รูปทรงกลมขนาดใหญ่ กึ่งกลางฉาก
   - **พื้นผิว (Texture):** ใช้ Procedural Canvas Shader หรือ Gradient Texture สไตล์ Give Love Studio โทนสีละมุน (พาสเทลชมพู-ม่วง-ฟ้าคราม สไตล์ท้องฟ้ายามโพล้เพล้หรือเมฆนุ่ม)
   - **ชั้นบรรยากาศเรืองแสง (Atmospheric Glow / Fresnel Rim Light):**
     - สร้างทรงกลมชั้นนอกครอบดวงดาวอีก 1 ชั้นที่ใช้ Custom Shader หรือ BackSide Material เรืองแสงสีฟ้าอมชมพูรอบขอบดวงดาวอย่างนุ่มนวล
   - **วงแหวนละอองดาว (Cosmic Dust Ring):** วงแหวนฝุ่นดาวและอัญมณีจิ๋วหมุนเอียงรอบดวงดาวช้าๆ เพิ่มมิติความลึก

---

### เฟส 2: ระบบปักหมุดความทรงจำ 5 จุด (5 Interactive Memory Beacons)
กำหนดให้มีหมุดความทรงจำทั้งหมด **5 จุด** กระจายอยู่ตามพิกัดทรงกลม (Spherical Coordinates) รอบดวงดาวอย่างสมดุล:

1. **ลักษณะของหมุด 3D แต่ละจุด:**
   - **เสาแสงเรืองรอง (Light Beacon):** ลำแสงพุ่งขึ้นจากพื้นผิวดาวในแนว Normal Vector
   - **วงแหวนคลื่นพลังงาน (Pulsing Rings):** วงแหวนระลอกคลื่นขยายตัวและจางหายรอบฐานหมุดตลอดเวลา
   - **ป้ายตัวเลขลอย (Floating Number Badge):** ไอคอนทรงกลมกระจกฝ้าแสดงตัวเลขลำดับ `01`, `02`, `03`, `04`, `05` พร้อมไอคอนรูปหัวใจดวงเล็กๆ ลอยกระเพื่อมขึ้นลงเบาๆ (Floating hover)
2. **รายชื่อและธีมของ 5 ความทรงจำ (Mockup Data ที่แก้ได้ง่าย):**
   - **Memory 01:** "The First Day" (วันแรกที่เราได้รู้จักกัน) — วันที่และสถานที่แรกพบ
   - **Memory 02:** "Our Favorite Cafe" (คาเฟ่โปรดกับรอยยิ้มของคุณ) — กลิ่นกาแฟและช่วงเวลาพิเศษ
   - **Memory 03:** "First Trip Together" (ทริปแรกของการเดินทาง) — วิวทะเล/ภูเขาที่เราไปด้วยกัน
   - **Memory 04:** "Little Moments, Big Love" (เรื่องเล็กๆ ที่ทำให้ตกหลุมรักซ้ำๆ) — โมเมนต์ความอบอุ่นในวันธรรมดา
   - **Memory 05:** "Happy Birthday, My Universe" (สุขสันต์วันเกิด ดวงดาวที่สว่างที่สุดของฉัน) — คำอวยพรวันเกิดและสัญญาในอนาคต

---

### เฟส 3: แอนิเมชันการบินของมุมกล้อง (Cinematic Camera Fly-to Navigation)
1. **การควบคุมแบบ 360 องศา:**
   - หมุนดาวสำรวจได้อิสระด้วย OrbitControls (เปิด Smooth Damping)
   - มีระบบหมุนดาวอัตโนมัติช้าๆ เมื่อผู้ใช้ไม่ได้แตะจอ
2. **การคลิกหมุด (Raycasting Interaction):**
   - เมื่อนำเมาส์ไปชี้หรือแตะบนหมุด ป้ายตัวเลขจะเรืองแสงขยายใหญ่ขึ้น (Cursor: pointer)
   - เมื่อคลิกหมุด:
     - ปิดการทำงาน OrbitControls ชั่วคราว
     - ใช้ **GSAP** เคลื่อนย้ายตำแหน่งกล้อง (`camera.position`) และจุดโฟกัส (`controls.target`) บินพุ่งเข้าไปจ่อด้านหน้าหมุดนั้นอย่างนุ่มนวล (Ease: "power3.inOut" ระยะเวลา 1.5 วินาที)
     - ดวงดาวหมุนปรับมุมองศาให้อยู่ในแนวระนาบที่พอดีกับสายตา

---

### เฟส 4: การ์ดความทรงจำสไตล์ Glassmorphism (Memory Popup Card)
เมื่อกล้องบินเข้าถึงจุดหมาย ให้แสดงการ์ดความทรงจำเด้งขึ้นมา:
1. **ดีไซน์การ์ด:**
   - ดีไซน์กระจกฝ้าแบบพรีเมียม (Backdrop-filter blur, ขอบเส้นเรืองแสงสีขาวบางเฉียบ)
   - ด้านบนมีป้ายแท็กวันที่และชื่อหมุด
   - **กรอบรูปโพลาลอยด์ 3D:** แสดงรูปคู่ (ใส่ Placeholder รูปสวยๆ จาก Unsplash ไว้ และมีช่องคอมเมนต์บอกวิธีเปลี่ยนเป็นรูปคู่จริง) โดยรูปจะเอียงตามการขยับเมาส์ (Parallax Tilt Effect)
   - **กล่องข้อความบรรยาย:** ฟอนต์สไตล์มินิมอล อ่านง่าย ละมุนตา
2. **ปุ่มควบคุมภายในการ์ด:**
   - ปุ่ม **"ความทรงจำถัดไป ➔"** (กดแล้วกล้องจะบินต่อไปยังหมุดหมายเลขถัดไปทันทีโดยไม่ต้องกดย้อนกลับ)
   - ปุ่ม **"⤶ ถอยกลับสู่จักรวาล"** (กดแล้วกล้องจะบิน Zoom Out กลับสู่มุมมองดาวเต็มดวง พร้อมเปิด OrbitControls อีกครั้ง)

---

### เฟส 5: ฟังก์ชันเสริมสุดโรแมนติก (Romantic Extras)
1. **เครื่องเล่นเพลงลอยได้ (Floating Music Player Widget):**
   - มุมจอมีปุ่มเปิด-ปิดเพลงรูปแผ่นเสียงไวนิลจิ๋วหมุนได้ มีคลื่นเสียงขยับขึ้นลง
   - ใส่เพลง BGM ดนตรีอะคูสติก/เปียโนหวานๆ คลอเบาๆ
2. **ปุ่มขอพรดาวตก (Make a Wish Button):**
   - ปุ่มกดรูปดาวมุมขวาล่าง: *"อธิษฐานขอพรดวงดาว ✨"*
   - เมื่อกด จะมีฝนดาวตกชุดใหญ่พุ่งผ่านหน้าจอ พร้อมเอฟเฟกต์ละอองหัวใจสีทองเปล่งประกาย
3. **ข้อความต้อนรับด้านบน:**
   - ไตเติลลอยโปร่งแสง: *"Our Little Planet · ดวงดาวแห่งความทรงจำ"*

## 4. มาตรฐานคุณภาพและการตรวจสอบ (Verification Checklist)
- [ ] **การเรนเดอร์กราฟิก:** ดวงดาวต้องมีแสง Rim Light ละมุนตา ไม่แบนราบ บรรยากาศอวกาศมืดลึกระยิบระยับเหมือนในคลิปต้นฉบับ
- [ ] **ระบบกล้อง GSAP:** จังหวะซูมเข้าและซูมออกต้องนุ่มนวล ไม่กระตุกหรือมุมกล้องหลุดเข้าไปในเนื้อดาว
- [ ] **รองรับหน้าจอมือถือ 100%:** ทดสอบบน Mobile Viewport แตะหมุนได้ง่าย ตัวหนังสือและปุ่มในการ์ดไม่ล้นจอ
- [ ] **ความสมบูรณ์ของโค้ด:** รันผ่านไฟล์ HTML เดี่ยวๆ หรือโปรเจกต์ได้ทันที รูปและเสียงมี Fallback ปลอดภัย ไม่เกิดข้อผิดพลาด 404

## 5. ลำดับขั้นตอนการสั่งงาน Agent (Execution Steps)
1. ติดตั้ง Three.js, GSAP และ Font สวยๆ
2. สร้างฉากอวกาศ Starfield + ดาวตก
3. สร้าง Mesh ดวงดาว ทรงกลมพร้อม Material ไล่เฉด และชั้นบรรยากาศ Fresnel
4. คำนวณพิกัดตรีโกณมิติปักหมุด 5 จุดรอบดาว พร้อมใส่แสง Beacon และป้ายหมายเลข 01-05
5. เขียน Raycasting ดักจับคลิก และเขียนแอนิเมชัน GSAP พาบินเข้าหาหมุด
6. สร้าง UI Card กระจกฝ้าแสดงรูปและข้อความ พร้อมปุ่ม Next / Back to Galaxy
7. ใส่ Widget เพลงและปุ่มขอพรดาวตก
8. ตรวจสอบบน Browser Preview ให้สมบูรณ์แบบ
