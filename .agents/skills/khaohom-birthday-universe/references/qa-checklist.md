# รายการตรวจสอบคุณภาพ (QA Checklist)

ใช้ตรวจสอบก่อนและหลังการปรับปรุงทุกรอบ โดยเฉพาะรอบ 9

## 1. การทำงานของระบบไกด์ (Phase A)
- [ ] ไกด์ขึ้นเพียง 1 ครั้งต่อฉาก ไม่ขึ้นซ้ำเมื่อย้อนกลับมาหรือกด "เป่าเทียนอีกครั้ง" / "ดูความทรงจำอีกครั้ง"
- [ ] ไม่มีไกด์ค้างเมื่อแตะข้ามฉากหรือสลับฉากอย่างรวดเร็ว
- [ ] ใช้ `src/ui/guideLedger.js` บันทึกสถานะ และเกษียณ (`retire`) เมื่อผู้ใช้ทำตาม
- [ ] คำว่า "เปิดการ์ด" ถูกเปลี่ยนเป็นชี้ดาวดวงแรกอย่างชัดเจน: "แตะ **ดาวศุกร์** ดวงแรกเลย แล้วดูว่ามีอะไรรออยู่ 👆"
- [ ] ข้อความใน help sheet และ HUD hint อ้างถึง "ดาวศุกร์" และไม่มีคำว่า "สีทอง"
- [ ] ตัวทดสอบ `?guide=reset` ล้างประวัติไกด์ได้จริง

## 2. การตัดก้อนฟุ้งสีทอง (Phase B)
- [ ] ก้อน bulge (กระจุกดาวใจกลางครีม-ทองเหนือหัวใจ) ใน `spiralGalaxy.js` ถูกนำออกสมบูรณ์
- [ ] ในมุมมอง Epilogue / Galaxy View ไม่เหลือก้อนแสงสีทองฟุ้งลอยอยู่เหนือหัวใจ
- [ ] โทนสีรวมเป็น ม่วง / ชมพู / โรสโกลด์ / ลาเวนเดอร์ / ขาว

## 3. จังหวะการเป่าเค้ก (Phase D)
- [ ] แตะหรือเป่าไมค์แล้ว เปลวเทียนเริ่มเอนและแสงสั่นไหวทันที (0–0.6s)
- [ ] เทียนดับทีละเล่ม ห่างกัน 220–260 ms พร้อมควันสีลาเวนเดอร์บางๆ และเสียงโน้ตดนตรี
- [ ] กล้องดันเข้าเล็กน้อยและแสงเค้กลดลงอย่างนุ่มนวล
- [ ] เมื่อดับครบทุกเล่ม มีช่วงหยุดนิ่งมืดลง ~0.5s เพื่อดื่มด่ำความเงียบและดวงดาว ก่อนเริ่มฉลอง
- [ ] โหมดไมค์: ต้องเป่าลมต่อเนื่อง ≥ 0.7s จึงจะดับ เสียงพูดสั้นๆ หรือเสียงรบกวนไม่ทำให้ดับ
- [ ] แตะซ้ำหรือรัวแตะไม่มีผลข้างเคียง และ timer ทั้งหมดถูกล้างเมื่อออกจากฉาก

## 4. การฉลอง ฉากจบ และดาวตก (Phase E)
- [ ] หลังเทียนดับ มีระเบิดประกายดาวใหญ่ + พลุเป็นชุด (6–7 ลูก) ยิงต่อเนื่องสลับซ้าย-ขวา
- [ ] ฝนดาวตก 3 คลื่น (รวมเห็นพร้อมกัน ≥ 8 ดวงบนหน้าจอ) คำนวณทิศจากมุมกล้องปัจจุบัน ไม่หลุดเฟรม
- [ ] เค้กค่อยๆ จมลงอย่างนุ่มนวล (≥ 1.4s) พร้อมกับกล้องถอยเข้ามุม Epilogue
- [ ] จากเทียนดับถึงเข้า Epilogue ใช้เวลารวม ~7–8 วินาที
- [ ] ใน Epilogue: 0–5s ปล่อยให้ดูดาวตก/พลุโดยไม่มีไกด์รบกวน
- [ ] ~5s ปุ่มดูกาแล็กซี่เริ่มเต้นเรืองแสงเบาๆ ด้วย CSS
- [ ] ~9s หากยังไม่กด แสดง toast สั้น + สปอตไลต์บางๆ ครั้งเดียว และหายถาวรเมื่อกดปุ่ม

## 5. วาร์ปลอดประตูดาว (Phase C)
- [ ] ริบบิ้นแสงมีหัวสว่าง-หางจาง ไล่สีขาว-ชมพู-ม่วง ไม่ใช่เส้น 1px สีรุ้ง
- [ ] ประตูสตาร์เกตมีขนาดสัมพันธ์กับหน้าจอ (รองรับ portrait/landscape)
- [ ] กล้องบินพุ่งตรงตามแกนลอดผ่านศูนย์กลางประตู มีจังหวะแฟลชลอดผ่านชัดเจน
- [ ] ซ่อนระบบสุริยะ ป้าย วงโคจร บีคอน ตลอดช่วงวาร์ป
- [ ] ปุ่มข้ามทำงานได้อย่างนุ่มนวล (fade) และรัวแตะไม่พัง

## 6. วงโคจรและดาวเคราะห์ (Phase F)
- [ ] วงโคจรมีความหนาบนหน้าจอคงที่ (≥ 1.5 px บนมือถือ)
- [ ] สว่างเด่นที่ตำแหน่งดาวพร้อมหางจางย้อนหลัง
- [ ] สีกำกับตามความทรงจำ
- [ ] วงโคจรของดวงถัดไปเต้นหายใจเด่นชัด
- [ ] ป้ายชื่อแสดงเฉพาะดวงถัดไป / ดวงที่ hover / ดวงที่กำลังโฟกัส ไม่ซ้อนทับกัน
- [ ] ดาวเคราะห์แตะง่าย (hit area ≥ 44×44px)

## 7. ตรวจสอบบั๊กและความเข้ากันได้ (Phase G & H)
- [ ] `npm run build` สำเร็จไม่มี error
- [ ] ไม่มี timer ค้าง (`clearTimeout`, `gsap.killTweensOf`)
- [ ] รองรับ Safe Area Insets (`100dvh`, `viewport-fit=cover`)
- [ ] บันทึกและตรวจสอบภาพ QA ใน `qa/round9-*` ครบทุกฉาก
