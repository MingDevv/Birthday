# สเปกฉาก (ตัวเลขที่ใช้ตัดสิน ปรับได้แต่ต้องบันทึกเหตุผล)

อ่านไฟล์นี้เมื่อต้องแก้ วาร์ป / เค้ก / ฉากจบ / ดาวตก / ไกด์ / วงโคจร แผนละเอียดของรอบล่าสุดอยู่ใน `แผนรอบ N-*.md` ที่โฟลเดอร์ราก

## 1. วาร์ป "ลอดประตูดาว" (~8 วินาที)

| เวลา | ภาพ | กล้อง | เสียง |
|---|---|---|---|
| 0.0–1.0 ชาร์จ | ประตูใหญ่ (รัศมีสัมพันธ์ `min(w,h)`) เรืองม่วง-ชมพู ดาวเริ่มยืดช้าๆ | FOV 55 นิ่ง สั่นเบา | riser |
| 1.0–2.4 พุ่ง | ประตูขยายเต็มจอ ริบบิ้นแสงยืดจากกลางจอ | บินตรงตามแกน −Z FOV 55→92 ease-in | whoosh ไต่ขึ้น |
| 2.4–2.7 ลอดผ่าน | แฟลชชมพู-ขาว 120 ms | FOV กระชาก + chromatic aberration พุ่งสั้น | boom ต่ำ + `navigator.vibrate(25)` |
| 2.7–6.0 อุโมงค์ | กลางจอโล่ง ริบบิ้นนุ่มวิ่งออกขอบ วงแหวนผ่านทุก ~0.5s | ความเร็วคงที่ roll ±0.04 | ลมแผ่ว |
| 6.0–8.0 ออก | เส้นหดสั้น แสงวาบจางเป็นท้องฟ้ามืดคม | FOV 92→hero ease-out | ประกายระฆังเบา |

- ริบบิ้น: instanced quad หัวขาว-กลางชมพู-หางม่วง, `AdditiveBlending`, `depthWrite:false`
- จำนวน: high 400 / medium 280 / low 120 (มือถือใช้ medium หรือต่ำกว่า)
- ซ่อนระบบสุริยะ ป้าย วงโคจร บีคอน ตลอด `FLIGHT` (`solarSystem.setTransitMode(true)`)
- ปุ่ม "ข้ามฉากเดินทาง" ตำแหน่งเดียว ไม่มีข้อความซ้ำ ข้าม = fade 300 ms

## 2. ละอองเป็นคำ "ข้าวหอม" (ห้ามถอยจากรอบ 7)

- billboard หน้ากล้อง กว้าง ≤ 85% ของจอ อยู่กลาง safe area
- ซ่อนดาวเคราะห์ วงโคจร บีคอน หัวใจ ระหว่างค้างคำ แล้วคืนค่า
- ค้างให้อ่านอย่างน้อย 2 วินาที
- reduced-motion: แสดงคำครบทันที

## 3. ดับเทียน

| เวลา | เหตุการณ์ |
|---|---|
| 0–0.6s | เปลวเอนตามลม กระพริบ แสงสั่น |
| 0.6s → | ดับทีละเล่ม ห่าง 220–260 ms (รวม ≈ 2–2.6s) มีควันบางสีลาเวนเดอร์ + โน้ต music-box ไล่ขึ้น (เพนทาโทนิก) |
| ระหว่างดับ | `cakePointLight` ลดต่อเนื่อง กล้องดันเข้า ~4–6 หน่วย |
| เล่มสุดท้าย | หยุดนิ่ง 0.5s ฉากมืด เห็นดาว |

**ไมค์:** สะสมเวลาที่ RMS > ~0.11 ให้ถึง ≥ 0.7s (อิงเวลา ไม่ใช่นับเฟรม) หลุดแล้ว decay ช้าๆ เปลวเอนตามความแรงเป็นฟีดแบ็ก ปุ่มแตะ = เล่นชุดดับทั้งหมด กดซ้ำไม่มีผล

## 4. ฉากจบ "คำอธิษฐานของข้าวหอม" (หลังเทียนดับ ≈ 7–8s)

| เวลา | เหตุการณ์ |
|---|---|
| 0.0–0.5 | นิ่ง ฉากมืด |
| 0.5 | ระเบิดดาวใหญ่ + ระฆัง |
| 0.9–3.4 | ชุดพลุ 6–7 ลูก ห่าง ~0.4s โค้งซ้าย-ขวา สลับสี ม่วง/ชมพู/โรสโกลด์/ขาว |
| 1.0–7.0 | ฝนดาวตก 3 คลื่น (0, 1.6, 3.2s) คลื่นละ 10–14 ดวงตาม tier + ฝนผงดาวบางๆ |
| 3.0 | แบนเนอร์อธิษฐานของระบบ (ข้อความเดิม) |
| 5.0–6.6 | เค้กจมช้า 1.6s + แสงจาง |
| 5.0–7.4 | กล้องถอยไปมุมหัวใจ |
| 7.4 → | ถ้า `finalMessage` มี: จดหมาย / ถ้าว่าง: เข้า EPILOGUE พร้อมดาวตกเบาๆ ต่อ |

**EPILOGUE:** `setAmbientBoost(×3)` 25 วินาทีแรกแล้วลดกลับ พลุเบาๆ ทุก ~6–8s ไม่เกิน 3 ครั้ง ปุ่ม "ดูความทรงจำอีกครั้ง / เป่าเทียนอีกครั้ง / เก็บภาพ" ขึ้นหลัง ~3s

**พาไปกดกาแล็กซี่ (ชั้นๆ):** 0–5s ไม่มีไกด์ → ~5s ปุ่ม `#btn-toggle-galaxy` เต้นเรืองด้วย CSS → ~9s ถ้ายังไม่กด toast บรรทัดเดียว + สปอตไลต์บาง ครั้งเดียว → กดแล้ว `ledger.retire('galaxy-hint')` ถาวร

## 5. ดาวตก (`galaxySkybox.js`)

- pool: high 36 / medium 24 / low 12 เมื่อเต็มให้เข้าคิว (สูงสุด ~20)
- API ที่ต้องมี: `triggerCelebrationShower({ waves, perWave, interval })`, `setAmbientBoost(mult, seconds)`
- จุดเริ่ม/ทิศคำนวณจากกล้องปัจจุบัน ต้องอยู่ในเฟรมเสมอ (ครึ่งบนของจอลู่ลง)
- สี ม่วง/ชมพู/ลาเวนเดอร์/ขาว ทอง ≤ 1 ใน 5
- ปกติ: ทุก 1.2–2.4s (คงเดิม) เมื่อ boost: 0.35–0.7s ค่อยๆ กลับ

## 6. วงโคจร

- ความหนาบนจอคงที่ (≥ ~1.5 px มือถือ)
- สว่างที่ตำแหน่งดาว หางจางย้อนหลัง ±70°
- สีตามความทรงจำ ลดความอิ่ม
- opacity: ปกติ 0.20 / เยี่ยมแล้ว 0.34 / ชี้หรือดวงถัดไป 0.55 (หายใจ)
- เยี่ยมแล้ว: จุดแสงวิ่ง 1 จุด

## 7. ดาวเคราะห์

- สเกลภาพ ×1.2–1.4 (มือถือแนวตั้ง ×1.5) แยกจาก `radius` ที่ใช้คำนวณฟิสิกส์/วงโคจร
- พื้นที่แตะ ≥ 44×44 px (ใช้ sphere โปร่งใสใหญ่กว่าเล็กน้อยสำหรับ raycast)
- ไฟจากหัวใจให้ด้านในสว่าง ด้านนอกมืดนุ่ม
- ขอบบรรยากาศสีตามความทรงจำ ความหนาสม่ำเสมอ
- ดวงถัดไป: วงแหวนบิลบอร์ดสีชมพูอ่อน หมุนช้า (ไม่ใช้ทอง)
- เยี่ยมแล้ว: เครื่องหมาย ✓ เล็กที่ดาว ไม่ใช่ป้ายยาว
