# ดาวลูกหมู-001 · กติกาการแก้โปรเจกต์

โปรเจกต์นี้คือของขวัญวันเกิดที่มีผู้รับคนเดียว (ข้าวหอม อายุ 16) ทุกรายละเอียดมีน้ำหนักทางอารมณ์ สิ่งที่เคยพังซ้ำๆ คือ **ของซ้อนกัน, ไกด์ขึ้นซ้ำ, ภาพไม่ชัดบนมือถือ, จังหวะเร็วเกินไป, และ timer ที่ไม่ถูกยกเลิก** skill นี้มีไว้กันทั้งหมดนั้น

## ลำดับการทำงาน (ทำตามทุกครั้ง)

1. **อ่านก่อนแก้:** เปิดไฟล์ที่เกี่ยวข้องจริง (ดู "แผนที่โค้ด") และแผนล่าสุดในโฟลเดอร์ราก (`แผนรอบ N-*.md`) ห้ามแก้จากความจำ
2. **ระบุต้นเหตุ ไม่ใช่อาการ:** อาการ "ฟุ้ง/เบลอ/ซ้อน" ให้หาว่าเป็น object ตัวไหน (ชื่อไฟล์ + บรรทัด) แล้วเอาตัวนั้นออก/แก้ ห้ามกลบด้วยหมอก bloom หรือ opacity
3. **แก้เท่าที่ขอ:** ไม่เพิ่มฉาก/ฟีเจอร์/ข้อความใหม่ที่ไม่ได้ขอ ถ้าเห็นสิ่งที่ควรแก้อีก ให้บันทึกเป็นข้อเสนอท้ายรายงาน
4. **build:** `npm run build` ต้องผ่าน
5. **ตรวจด้วยภาพจริง** ตาม `references/qa-checklist.md` เปิดดูภาพทุกภาพด้วยตา ภาพที่ไม่ได้เปิดดู = ยังไม่ผ่าน
6. **รายงาน** แยก 3 ส่วน: ทำแล้วและยืนยันด้วยภาพ / ทำแล้วแต่ยังไม่ยืนยัน (เช่น ยังไม่ทดสอบเครื่องจริง) / ข้อเสนอเพิ่มเติม ห้ามอ้างว่า "ผ่านบนมือถือ" ถ้ายังไม่ได้ทดสอบบนมือถือจริง

## ห้ามแตะโดยพลการ (ข้อความและรูปของเจ้าของ)

- `src/config/memoriesData.js`: title / description / quote / thaiSubtitle / date / รูป
- `OPTIONAL_FEATURE_CONTENT.secretMessage` ("มีความสุขมากๆนะไอ่อ้วนน💗") ต้องคงถ้อยคำเดิมทุกตัวอักษร
- `finalMessage`, `shootingStarMessages`, `birthdayDate` เจ้าของยังไม่ใส่ (ว่าง) **ห้ามแต่งแทน** ต้องทำให้ฉากสมบูรณ์ได้ทั้งแบบมี/ไม่มี
- `public/images/memory-*.jpg`, เพลงใน `public/audio/`
- ข้อความของระบบ (ไกด์/ปุ่ม) แก้ได้ แต่ต้องอยู่ใน `src/config/guideCopy.js` ที่เดียว

ลำดับดาว (ไม่มีดาวพุธ): **1 ศุกร์ → 2 โลก+จันทร์ → 3 อังคาร → 4 พฤหัสบดี → 5 เสาร์** เรียกดวงแรกว่า "ดาวศุกร์"

## กติกาข้อที่ 1 — ไกด์ขึ้นครั้งเดียวต่อฉาก

- ทุกไกด์/bubble/spotlight/toast ต้องมี **id** และผ่าน `ledger.seen(id)` ก่อนแสดง (`src/ui/guideLedger.js`, เก็บใน `sessionStorage` พร้อม fallback ในหน่วยความจำ)
- **retire เมื่อผู้ใช้ทำตาม** (แตะเป้าหมาย/กดปิด) ไม่ใช่แค่เมื่อมันขึ้น
- ห้ามมีข้อความเดียวกันสองช่องทาง (เช่น toast + bubble + ปุ่ม เรื่อง "ข้ามฉากเดินทาง")
- เปลี่ยนฉากแล้ว ไกด์ของฉากเก่าต้องหายทันที (`clearAllGuides`) และ timer ที่ตั้งไว้ต้องถูกยกเลิก
- idle nudge ห้ามรีเซ็ตตัวนับเมื่อเปลี่ยน state ให้ขึ้นได้รวมกันไม่เกิน 3 ครั้งต่อ session
- บอกชื่อสิ่งที่ให้กด ไม่ใช้คำกว้างๆ: ใช้ "แตะดาวศุกร์" ไม่ใช้ "เปิดการ์ด" ชื่อดาวดึงจาก `progress.getNextId()`
- คำแนะนำทั่วไปที่ไม่จำเป็นต้องบังคับ ใช้ toast สั้นหนึ่งบรรทัด ไม่ใช้ spotlight/กล่อง
- ตัวรีเซ็ตสำหรับทดสอบ: `?guide=reset`

## กติกาข้อที่ 2 — ไม่มีอะไรซ้อนกัน

- ตำแหน่งปุ่ม/ข้อความทุกชิ้นต้องผ่าน `uiDirector` (zone) หรือกลุ่ม dock เดียว **ห้ามกำหนด `bottom: 58px / 76px / 78px` เป็นเลขลอยแยกปุ่ม**
- กฎ CSS ของส่วนเดียวกันอยู่ที่เดียว ห้ามเขียนซ้ำหลาย `@media` แล้วชนะด้วย `!important`
- ความสูงจอใช้ `100dvh` (ใส่ `100vh` เป็น fallback เท่านั้น), มี `viewport-fit=cover` ใน `index.html`, ใช้ `env(safe-area-inset-*)` ทั้งบนและล่าง, **ห้าม** `user-scalable=no`
- พื้นที่แตะ ≥ 44×44 CSS px
- ป้ายชื่อใน 3D แสดงเฉพาะ ดวงถัดไป / hover / โฟกัส บนมือถือแสดงเฉพาะดวงถัดไป
- ก่อนรายงาน: ตรวจ `getBoundingClientRect` ของ UI ที่มองเห็นทุกชิ้นว่าไม่ทับกัน ที่ 360×740, 390×844, 844×390, 768×1024, 1280×720 ในทุก state หลัก (EXPLORE, MEMORY, FINALE_CAKE, EPILOGUE)

## กติกาข้อที่ 3 — จังหวะ (ห้ามเร็วจนไม่ทันรู้สึก)

| ช่วง | ขั้นต่ำ/เป้าหมาย |
|---|---|
| วาร์ป | รวม 7.5–8.5 วินาที ปุ่มข้ามกดได้ตลอด |
| ละอองรวมเป็นคำ "ข้าวหอม" | ค้างให้อ่านอย่างน้อย 2 วินาที |
| ดับเทียน | ห่างเล่มละ 220–260 ms รวม ≈ 2–2.6s + หยุดนิ่ง 0.5s |
| ฉากฉลองหลังเทียนดับ | 7–8 วินาทีก่อนเข้า EPILOGUE (ห้ามตัดใน 1 วินาที) |
| เค้กจมออก | ≥ 1.4 วินาที |
| จดหมายตอนจบ (ถ้ามี) | อ่านได้ ≥ 3.5s + ~60 ms/ตัวอักษร แตะเพื่อปิด |
| ไกด์กาแล็กซี่หลังจบ | ขึ้นหลังพลุเบาลง (~5–9s) ไม่ทับพลุ |

ทุกจังหวะต้องมีเวอร์ชัน `prefers-reduced-motion` และ `?fx=off` ที่สั้นลงแต่ยังครบความหมาย

## กติกาข้อที่ 4 — ภาพ/เอฟเฟกต์

- **Palette:** ม่วง `#a855f7`, ลาเวนเดอร์ `#c084fc`/`#d8b4fe`, ชมพู `#f472b6`, โรสโกลด์ `#fda4af`, ขาว ทอง `#fde68a` ใช้เป็นประกายเล็กๆ ได้ไม่เกิน ~1 ใน 5 ของสีในฉากหนึ่ง **ห้ามมีก้อนฟุ้ง/หมอกสีทอง-ครีม** (เคยมี: `spiralGalaxy.js` กระจุก bulge ที่ลอยเหนือหัวใจ ถูกสั่งลบแล้ว อย่าสร้างกลับมา)
- ห้ามกลบปัญหาด้วย bloom/หมอก/opacity เพิ่ม ให้เอาต้นเหตุออก
- เส้น WebGL (`LineBasicMaterial`) หนาได้แค่ 1px ถ้าต้องการเส้นแสงให้ใช้ instanced quad/shader ยืดตามความเร็ว
- ความหนาของเส้นสำคัญ (วงโคจร) ต้องคงที่บนจอตามระยะกล้อง อย่างน้อย ~1.5 px บนมือถือ
- ฉากที่ต้องการให้ผู้ชมโฟกัส (ละอองเป็นคำ, ชื่อ 3D, เค้ก) ต้อง **ซ่อน/หรี่ของรอบข้าง** (ดาวเคราะห์ วงโคจร ป้าย บีคอน) แล้วคืนค่าทุกเส้นทางออก (จบ, ข้าม, เปลี่ยน state, resize)
- ข้อความ 3D/ละอองต้องหันเข้ากล้อง (billboard) และพอดีกับ viewport ≤ ~85% ของความกว้างจอ ทั้งแนวตั้ง-แนวนอน
- ตัวอักษรไทยบน canvas ต้องรอ `document.fonts.load()` ก่อนวาด และมี fallback `'Prompt','Kanit','Noto Sans Thai',sans-serif`

## กติกาข้อที่ 5 — Timer, event, memory (ต้นเหตุบั๊กซ้อน/ซ้ำ)

- ทุก `setTimeout`/`setInterval`/`gsap.delayedCall`/`gsap.to` ที่ผูกกับฉากต้อง **เก็บ id/ตัวแปร** แล้ว `clear`/`kill` ตอนออกฉาก ใช้ `flow.after()` และ `flow.track()` ที่มีอยู่
- ฟังก์ชันเริ่มฉาก (`startNameReveal`, `startCaption`, `startArrivalShape`, `blowOut` ฯลฯ) ต้องมี guard กันเรียกซ้ำ (flag หรือเช็ค `currentStep`)
- ผู้ใช้แตะข้ามขั้น = ต้องยกเลิก timer ที่รอเรียกขั้นเดียวกันด้วย
- `window` listener ที่เพิ่มต้อง `remove` ครบทุกเส้นทางที่ออกฉาก
- สร้าง geometry/material/texture ใหม่ ต้อง `dispose` ตอนจบ เช็ค `renderer.info.memory` ก่อน-หลังฉากต้องไม่โตขึ้น
- ในลูป `update` ห้ามสร้าง object ใหม่ (`new Vector3` ฯลฯ) ใช้ตัวแปรที่ใช้ซ้ำ
- pool ที่เต็มต้องเข้าคิวหรือรายงาน ห้ามทิ้งเงียบ (เคยเป็นเหตุให้ดาวตกไม่ออก)

## กติกาข้อที่ 6 — ประสิทธิภาพ/มือถือ

- จำนวนอนุภาค/เส้น/ดาวตกกำหนดตาม quality tier ใน `quality.js` (high / medium / low) ไม่ใช่เลขคงที่
- เป้า 60 FPS บนเดสก์ท็อป และไม่ต่ำกว่า ~30 FPS บนมือถือกลาง ถ้าต่ำกว่านั้นให้ลดตาม tier ก่อนจะลดดีไซน์
- ภาพจาก SwiftShader/headless **ไม่ใช่หลักฐาน FPS หรือความคม** บอกชัดในรายงานเสมอ
- รองรับ `visibilitychange` (หยุดไมค์/เสียงเมื่อสลับแท็บ), หมุนจอระหว่างฉาก, in-app browser (LINE/Instagram) ที่ความสูงจอเปลี่ยนได้

## ข้อผิดพลาดที่เคยเกิด (อย่าทำซ้ำ)

1. แตะข้ามฉาก แล้ว timer เดิมยังยิงต่อ → ชื่อ 3D ซ้อนสองชั้น, caption เด้งซ้ำ
2. รูปละอองวางบนระนาบตั้ง ขณะกล้องมองจากบน → รูปถูกบีบเหลือ ~31% ของความสูง (ต้อง billboard)
3. ไกด์ขึ้นทุกครั้งที่เข้า state เพราะกั้นแค่บางตัวใน `sessionStorage`
4. `env(safe-area-inset-*)` ไม่ทำงานเพราะไม่มี `viewport-fit=cover`
5. ปุ่มมุมล่างซ้อนกันเพราะกำหนด `bottom` คนละที่ ชนะกันด้วย `!important`
6. ดับเทียน 80 ms/เล่ม + ฉลองครั้งเดียว + เค้กจม 0.7s → ฉากจบหายไปใน 1 วินาที
7. ดาวตกไม่ค่อยออกเพราะ pool 14 ดวงและทิ้งเงียบเมื่อเต็ม
8. เส้นวาร์ปเป็น `LineSegments` 1px สีรุ้ง กล้องไม่ได้ลอดผ่านประตูจริง
9. วงโคจรบาง/จาง (tube รัศมี 0.075, opacity 0.13) ป้ายชื่อ 5 ป้ายขึ้นพร้อมกันทับกัน
10. ชื่อ 3D ใน galaxy view บนมือถือใหญ่เกินจอ ถูกตัดขอบ
11. ก้อน bulge สีครีม-ทองลอยเหนือหัวใจในมุมมองกาแล็กซี่
