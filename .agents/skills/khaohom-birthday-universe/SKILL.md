# ดาวลูกหมู-001 · กติกาและคู่มือสถาปัตยกรรมโปรเจกต์

โปรเจกต์นี้คือของขวัญวันเกิดสุดพิเศษที่มีผู้รับคนเดียว (**ข้าวหอม อายุครบ 16 ปี**) ทุกรายละเอียดมีผลต่ออารมณ์และความรู้สึก สิ่งที่เคยพังซ้ำๆ ในอดีตคือ **ของซ้อนกัน, ไกด์ขึ้นซ้ำ, ภาพไม่ชัดบนมือถือ, จังหวะเร็วเกินไป, timer ที่ไม่ถูกยกเลิก, เพลงเริ่มใหม่เมื่อกดปิด-เปิด, และปุ่มการ์ดสุดท้ายไม่พาไปเป่าเค้ก** เอกสาร skill นี้รวบรวมกฎและสถาปัตยกรรมทั้งหมดไว้เพื่อป้องกันข้อผิดพลาดเหล่านั้น

---

## ลำดับการทำงาน (ทำตามทุกครั้ง)

1. **อ่านก่อนแก้:** ตรวจสอบไฟล์ที่เกี่ยวข้องจริงจาก "แผนที่โค้ด" และอ่านแผนล่าสุด (`แผนรอบ N-*.md`) ในรูท ห้ามแก้จากความจำ
2. **เขียนแผนก่อนทำ:** จัดทำเอกสารแผนการทำงานเป็นไฟล์ `.md` ทุกครั้งก่อนเริ่มแก้โค้ด เพื่อกำหนดขอบเขต ไฟล์ที่ต้องแก้ และเกณฑ์ผ่านที่ชัดเจน
3. **ระบุต้นเหตุ ไม่ใช่อาการ:** ค้นหาชื่อไฟล์และบรรทัดที่เป็นต้นเหตุจริง ไม่กลบปัญหาด้วยหมอก bloom หรือ opacity
4. **แก้เท่าที่จำเป็นและคงความส่วนตัวของเจ้าของ:**
   - ห้ามแก้รูปและข้อความใน `src/config/memoriesData.js` โดยพลการ
   - ห้ามแก้คำว่า `"มีความสุขมากๆนะไอ่อ้วนน💗"` ใน `OPTIONAL_FEATURE_CONTENT.secretMessage`
5. **Build & Test:** รัน `npm run build` และรัน Visual QA (`scripts/visual-qa.mjs`) ตรวจสอบความถูกต้อง

## 10 กติกาสำคัญที่ต้องยึดถือ (Core Rules)

### กติกาที่ 1: การ์ดสุดท้าย (Memory 05) ต้องนำทางสู่เค้กวันเกิดเสมอ
- เมื่อผู้ใช้อ่านความทรงจำที่ 5 จบ ปุ่มการ์ดหลักด้านขวาต้องเปลี่ยนเป็น **"ไปเป่าเค้กวันเกิด 🎂✨"**
- การคลิกปุ่มนี้ต้องปิด Modal และเริ่ม `startFinaleSequence()` ทันที ห้ามวนกลับไปดาวศุกร์ (ดาวที่ 1) เด็ดขาด

### กติกาที่ 2: ป้ายชื่อดาว 3D (Beacon Badge) ต้องกดได้ติดจริง
- ผู้ใช้บนมือถือมักจะใช้นิ้วแตะที่ตัวป้ายชื่อลอย (`beaconSprite`) มากกว่าแตะที่ลูกดาว
- ต้องรวม `beaconSprite` เข้าไปใน `interactiveMeshes` หรือปรับ Hitbox ให้ครอบคลุมทั้งตัวดาวและป้ายลอยด้านบน

### กติกาที่ 3: เพลง BGM ต้องเล่นต่อเนื่อง ไม่รีเซ็ตไป 0:00
- ฟังก์ชัน `startBGM()` ห้ามเรียก `this.bgmAudio.load()` ตอนเล่น/สลับเพลง เพราะจะทำให้เพลงรีเซ็ตกลับไปวินาทีที่ 0
- เรียก `.load()` เฉพาะกรณีแรกสุดเมื่อ element ยังไม่ได้ initialize
- ซิงค์สถานะหมุนของแผ่นเสียงไวนิลกับ Event `play` / `pause` จริงของ Audio element เพื่อป้องกันการหมุนหลอกเมื่อเบราว์เซอร์บล็อก Autoplay

### กติกาที่ 4: ไกด์และปุ่มแนะนำต้องมี Action ที่นำทางได้จริง
- เมื่อแสดงปุ่มแนะนำ เช่น "🌸 แตะดาวศุกร์ดวงแรกเลย 👉✨" การแตะที่ปุ่มต้องเรียกฟังก์ชันนำทาง (`flyToPlanet(1)`) ไม่ใช่แค่ลบปุ่มทิ้ง

### กติกาที่ 5: ไกด์ขึ้นครั้งเดียวต่อฉาก และห้ามมีอะไรซ้อนกัน
- ทุกไกด์ต้องเช็ค `ledger.seen(id)` ก่อนแสดง และ `retire` เมื่อผู้ใช้ทำตาม
- เปลี่ยนฉากต้องล้างไกด์เก่าทันที (`clearAllGuides`)
- ปุ่มและข้อความทุกชิ้นต้องผ่าน `uiDirector` จัด Zone และ Layer ชัดเจน ไม่ใช้ inline `bottom: xx px` ลอยๆ

### กติกาที่ 6: จังหวะเวลา (Timing & Pacing)
- วาร์ป Star Gate: 7.5–8.5s ไร้จอดำในทุก Tier
- ละอองคำว่า "ข้าวหอม": ค้างให้อ่านชัดเจน $\ge 2.0$s
- ดับเทียน: ห่างเล่มละ 220ms (15 intervals) + หยุดนิ่ง 0.5s รวมเวลา ~4.4s ก่อนเริ่มฉลอง
- เค้กจมลง: $\ge 1.4$s อย่างนุ่มนวล
- มี fallback ที่กระชับสำหรับ `prefers-reduced-motion` และ `?fx=off` เสมอ

### กติกาที่ 7: การล้างหน่วยความจำและ Timer
- ทุก `setTimeout`, `setInterval`, `gsap.to` ต้องเก็บ reference และสั่ง cancel ใน `cancelCelebration()` หรือเมื่อเปลี่ยน state
- มี Guard flag (`blown`, `celebrationActive`, `currentStep`) ป้องกัน Event ซ้ำซ้อน
- ทำความสะอาด Geometries / Materials / Textures ด้วย `.dispose()` เมื่อปลดระวาง

### กติกาที่ 8: มาตรฐานสีและบรรยากาศ (Color Palette)
- ธีมหลัก: Cosmic Purple Dream (ม่วง `#a855f7`, ลาเวนเดอร์ `#c084fc`, ชมพู `#f472b6`, โรสโกลด์ `#fda4af`)
- ห้ามใส่หมอกหรือก้อนฟุ้งสีทอง-ครีมขนาดใหญ่ลอยบดบังฉาก
- ข้อความและขอบดาวต้องคมชัด ไร้ Chromatic Aberration (`uCA = 0.0`)

### กติกาที่ 9: รองรับมือถือและหน้าจอสัมผัส 100%
- ความสูงจอใช้ `100dvh` (fallback `100vh`)
- รองรับ Safe Area (`env(safe-area-inset-*)`)
- พื้นที่สัมผัสปุ่ม $\ge 44 \times 44$ CSS px
- การวางโมเดลเค้กใน Portrait (390×844, 360×740) ต้องมีระยะขอบ ไม่ถูกตัดขอบซ้ายขวา

### กติกาที่ 10: การรักษาข้อมูลส่วนตัวของเจ้าของ
- ห้ามดัดแปลงข้อความ วันที่ และรูปภาพความทรงจำของข้าวหอมใน `src/config/memoriesData.js`
- รักษาข้อความเซอร์ไพรส์วันเกิดทั้งหมดไว้ให้ครบถ้วน 100%
